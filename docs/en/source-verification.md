# BN source verification

Baseline: official Cataclysm-BN main, commit `e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800` (2026-10-04). This audit inspected source, JSON loaders, bindings, examples, and existing test definitions. It did not build BN, run those tests, or run a DoGS mod. Source confirmation is not gameplay validation.

## Integration and persistence

- **Confirmed:** same-ID self copy-from copies the already loaded definition, then replaces that ID. Load order matters. [src/generic_factory.h:223](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/generic_factory.h#L223), [src/generic_factory.h:351](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/generic_factory.h#L351).
- **Confirmed:** MONSTER loads `lua_ai` at type level. `extend.special_attacks` appends without clearing inherited attacks; a full `special_attacks` field clears them, and a repeated attack ID replaces its definition. [src/monstergenerator.cpp:868](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monstergenerator.cpp#L868), [src/monstergenerator.cpp:1013](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monstergenerator.cpp#L1013), [src/monstergenerator.cpp:1455](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monstergenerator.cpp#L1455).
- **Confirmed:** instance values are strings and are serialized through Creature::store/load; missing keys return an empty string. [src/creature.cpp:1902](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/creature.cpp#L1902), [src/savegame_json.cpp:3735](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/savegame_json.cpp#L3735), [src/savegame_json.cpp:3795](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/savegame_json.cpp#L3795).
- **Confirmed:** runtime attacks start enabled; cooldown starts randomized. Enabled state and cooldown are saved and restored. The actor loader has no initial JSON enabled field. Disable only DoGS IDs in the callback before fallback. [src/monster.h:63](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.h#L63), [src/monster.cpp:420](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L420), [src/savegame_json.cpp:2075](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/savegame_json.cpp#L2075), [src/savegame_json.cpp:2275](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/savegame_json.cpp#L2275), [src/monstergenerator.cpp:1427](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monstergenerator.cpp#L1427).
- **Compatibility constraint:** another mod can replace the same dog's lua_ai, replace an attack ID, or clear all attacks. Preserving other attacks inside DoGS does not guarantee arbitrary mod-order compatibility. No DoGS integration matrix can be run before its JSON/callback exists.

## Callback and action economy

- Register in `game.monster_ai_functions[callback_name]`; callback receives the monster. Returning false or nil uses stock plan/decide/execute. Returning true claims the action. If position and moves remain unchanged, the wrapper deducts up to 100 moves. [src/monmove.cpp:124](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monmove.cpp#L124), [src/monmove.cpp:1865](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monmove.cpp#L1865).
- For untrained dogs, disable DoGS attacks then return false. If calling `run_normal_ai_turn()` explicitly, return true to avoid a second stock action. It executes plan, decide_action, and execute_action directly. [src/catalua_bindings_creature.cpp:544](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L544).
- `set_move_target(pos)` only sets a destination. `set_target(creature)` snapshots that creature's current position; nil clears the destination. Neither moves nor maintains a persistent target identity. `move_to(pos, force, step_on_critter, stagger_adjustment)` returns bool and executes a step with terrain/action costs; it is not an arbitrary waypoint pathfinding API. [src/catalua_bindings_creature.cpp:526](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L526), [src/catalua_bindings_creature.cpp:549](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L549), [src/monmove.cpp:2425](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monmove.cpp#L2425).
- Setting a waypoint and returning true alone does not move. Calling normal AI replans and may replace it. A reliable route-to-waypoint execution strategy remains an implementation/playtest task.

## Perception and pursuit

- **Correction:** tile scanning is optional. `gapi.get_all_monsters()`, `get_all_creatures()`, and `get_monsters_if(filters)` exist. Filter keys include `sees`, `within_range_of={range=..., monsters={...}}`, and `hostile_to`. Filters traverse active monsters; a small result radius does not imply a spatially indexed query. [src/catalua_bindings_game_creatures.cpp:19](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_game_creatures.cpp#L19), [src/catalua_creature_filters.cpp:55](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_creature_filters.cpp#L55), [src/catalua_creature_filters.cpp:141](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_creature_filters.cpp#L141).
- In the `sees={dog}` filter, the dog sees each candidate, not vice versa. For LURE, check the enemy's sight of the dog separately. `hostile_to` evaluates candidate attitude toward the supplied monster. [src/catalua_creature_filters.cpp:55](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_creature_filters.cpp#L55), [src/catalua_creature_filters.cpp:79](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_creature_filters.cpp#L79).
- Position, sight, attitude, effects, immunity, HP, speed, and move budget are exposed. Tile lookup is `gapi.get_creature_at(pos[, allow_hallucination])` / `get_monster_at`. [src/catalua_bindings_creature.cpp:199](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L199), [src/catalua_bindings_creature.cpp:236](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L236), [src/catalua_bindings_creature.cpp:338](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L338), [src/catalua_bindings_game.cpp:706](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_game.cpp#L706).
- **Partial:** `move_target()` is exposed, but `attack_target()` is not in the inspected monster bindings. In C++, attack_target resolves a visible nonfriendly creature at the destination; it is not a durable target handle. Compare enemy destinations and movement as evidence of pursuit, not proof of stable identity. Reacquire targets across turns and save/load; minimal binding needs remain open. [src/monster.cpp:1776](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L1776), [src/catalua_bindings_creature.cpp:506](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L506).

## Special attacks

- APIs: `has_special_attack(id)`, `get_special_attack_ids()`, `special_attack_enabled(id)`, `set_special_attack_enabled(id, bool)`, `special_attack_ready(id)`, `get_special_attack_cooldown(id)`, `set_special_attack_cooldown(id, turns)`, `use_special_attack(id)`. [src/catalua_bindings_creature.cpp:456](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L456).
- ready checks enabled/zero cooldown, not range or line of sight. use returns whether the actor handled an attempt, not whether it hit; true resets cooldown and spends the one-special-per-action budget. Misses can return true. False need not roll back actor side effects. Lua dispatch does not inherit stock pacified/hallucination checks or choose a target. DoGS must gate eligibility and establish the destination. [src/monster.cpp:3183](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L3183), [src/mattack_actors.cpp:380](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/mattack_actors.cpp#L380), [src/catalua_bindings_creature.cpp:458](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/catalua_bindings_creature.cpp#L458).

## Control effects

- **Confirmed:** generic melee invokes on_damage/effects only after positive actual damage. Armor can therefore prevent downed/leg-wound application even with effect chance 100. Zero-damage Takedown needs a custom application path or engine change. [src/mattack_actors.cpp:428](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/mattack_actors.cpp#L428).
- LUNGE beyond adjacency may grant 200 moves rather than move directly; adjacent hits use 3–7 bash and a 1/6 downed roll for 3 turns. It does not provide reliable Takedown. [src/monattack.cpp:4914](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monattack.cpp#L4914).
- Downed sets monster dodge to zero. In stock execute_action, attempting to stand returns false from move_effects and ends remaining moves; recovery likelihood depends on melee dice/sides. Direct Lua movement must respect movement-effect restrictions explicitly. [src/monster.cpp:2828](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L2828), [src/monster.cpp:3086](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L3086), [src/monmove.cpp:1601](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monmove.cpp#L1601).
- bite_actor adds infection-related effects when grabbed and can poison the attacker on toxic flesh. Generic melee remains the better physical-wound base. [src/mattack_actors.cpp:483](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/mattack_actors.cpp#L483).
- speed_mod loads as SPEED and modifies monster speed bonus; it is not a percentage multiplier by default. [src/effect.cpp:291](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/effect.cpp#L291), [src/monster.cpp:3990](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L3990).
- **Confirmed with JSON:** `iflesh` means Insect Flesh, not zombie flesh. `mon_zombie` uses `flesh` and has `WARM`, so it passes the ordinary bleed immunity check. Bleed can damage it and create blood; other zombie types must be checked individually. Monsters without WARM or without flesh are immune. Keep bleed in the Ankle Tear candidate; do not generalize from a material ID's spelling. [data/json/materials.json:713](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/data/json/materials.json#L713), [data/json/monsters/zed-classic.json:52](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/data/json/monsters/zed-classic.json#L52), [src/monster.cpp:2315](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L2315), [src/monster.cpp:4032](https://github.com/cataclysmbn/Cataclysm-BN/blob/e0e25e9d8b3cf0d3b663882a7faf5a44d8ace800/src/monster.cpp#L4032).
