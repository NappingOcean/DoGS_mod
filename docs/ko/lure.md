# LURE 유인 임무

## 목적

무리 외곽의 개체를 시각적으로 유인해 분리한다. 좀비 무리 전체를 끌어오는 소리 기반 유인은 핵심 기능에서 제외한다.

소리는 주변 적도 함께 끌 수 있어 개체 분리에 적합하지 않다.

## 기본 흐름

1. 무리 외곽의 적을 고른다.
2. 개가 의도적으로 해당 적의 시야에 들어간다.
3. 적이 실제로 개를 추격하는지 확인한다.
4. 추격이 붙으면 플레이어 반대 방향으로 유도한다.
5. 충분히 분리되면 측면으로 빠져 추격 축에서 벗어난다.
6. 적을 플레이어에게 다시 끌고 가지 않도록 우회해서 복귀한다.

단순히 거리를 벌린 뒤 플레이어에게 직선 복귀하는 방식은 허용하지 않는다. **BREAK_CONTACT** 단계가 필요하다.

## 상태 유지

LURE는 개체별 임무·단계 상태를 유지하는 multi-turn state machine으로 구현한다.

## 실패·중단 조건

- 도주 경로가 거의 없다.
- 포위 위험이 증가한다.
- 너무 많은 적이 개에게 붙는다.
- 새 적이 퇴로에 나타난다.
- HP 또는 위험 기준을 넘는다.
- 플레이어가 크게 이동하거나 새롭게 위협받는다.

위험 시 임무 완수보다 생존을 우선하고 ESCAPE / RETREAT로 전환한다. 수치 임계치는 미정이다.

추격 대상 식별과 우회 이동의 구현 제약은 [Lua API와 이동 구현](lua-and-movement.md)을 참조한다.
